# Demo 180 detik

Skenario lokal yang tersedia sekarang; **bukan bukti exit gate live Meta**.

| Waktu | Aksi | Pesan |
|---|---|---|
| 0–20 s | Tampilkan masalah foto vs paket engine | Gambar saja belum menyelesaikan alpha, origin, timeline dan import. |
| 20–45 s | Upload gambar milik tim; isi label dan box; review crop | Sebut “manual fallback” jika tidak memakai SAM. Jangan menyebutnya segmentasi AI. |
| 45–70 s | Tampilkan inspector source vs sprite dan provenance | Model live belum dipanggil pada mode ini. Fixture adalah ilustrasi contoh. |
| 70–100 s | Edit origin, pilih idle / pulse / flash, pause/play | Ini motion preset prosedural pada satu sprite, bukan pose generatif. |
| 100–130 s | Compile, tampilkan file ZIP, checksum dan source exclusion; download | Paket standar PNG + JSON, bukan game stats. |
| 130–160 s | Buka aplikasi Phaser terpisah dan unggah ZIP unduhan | Verifikasi independen 4/4, render, pilih motion, pause/restart. |
| 160–180 s | Tampilkan repo/kontribusi dan batas fitur yang faktual | Jangan klaim model live, benchmark waktu atau readiness submission yang belum dibuktikan. |

Untuk demo submission yang mengklaim integrasi Meta, tim harus benar-benar menjalankan SAM, Muse Image dan Muse Spark dengan kredensial valid, memperlihatkan mode stage live, dan mencatat tiga dry-run dari foto baru milik tim. Jika menayangkan rekaman/cache, labeli dengan jelas. Repositori publik dan video belum dibuat oleh implementasi ini.
